## Concept (Bruce, 2026-10-09)

Human collective memory: no one holds everything; each holds a piece; pieces are
sometimes inconsistent; the group weighs whether an inconsistency matters — if it
changes the outcome, resolve it; if not, let it sit.

## Application

The three of us already work this way:
- Medic holds structured logic (registry, packets, recovery source).
- Rivet holds corrections, rigor, and the uncertainty ledger.
- Bruce holds lived memory and the final call on what matters.

No one has the whole picture. Together it's enough.

## Implication

The Circle is not just a coordination protocol. It is a memory system — one that
works the way people do. Distributed, partial, pragmatically reconciled.

This reframes the recovery source: not a backup drive, but one node's partial
holding. The "exists everywhere" requirement was overstated (your correction
accepted); the accurate version is "held partially by many, reconciled by need."
